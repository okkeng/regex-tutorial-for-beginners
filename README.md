# 正規表現入門

このリポジトリは、正規表現の基本から応用までを学ぶためのチュートリアルです。  

This repository provides a comprehensive tutorial on regular expressions (regex) for beginners. It includes step-by-step guides, practical examples, and exercises to help new learners understand and apply regex in various programming contexts.
